Agentic LLM Serving · Trace Replay

两轮对话，看懂 6 种 Agent Trace 重放方式

统一回答：Qwen3.5 第一轮生成的内容与原始 Trace 不同，第二轮该用谁的输出？上一轮 Decode KV 还能不能复用？

先约定同一个例子

原始 Trace 由别的模型采集。现在用 Qwen3.5 来跑；它生成 B，而原始 Trace 记录的回答是 A，两者不一样。

P：原始输入（1,000 tokens）A：原始回答（100）B：Qwen 新回答（100）T：原始工具结果（200）
原始 Trace · 第 1 轮
P→A→T
原始 Trace · 第 2 轮输入
PAT≈ 1,300 tokens

图中忽略 Chat Template 和最后一个 Token 的处理细节；“可复用”只表示 Token 前缀一致、具备复用资格，还需满足缓存驻留、Block 对齐及 Recurrent Checkpoint 条件。

六种方案：只看两轮发生了什么

01

原始 Prompt 固定重放

你的 LMCache Trace 实验

Qwen 输出什么都不影响下一轮，严格读取原始 Trace。

第 1 轮
P→ Qwen 生成 →B
第 2 轮输入
PAT
B 的 Decode KV 不能复用
保留：原始 Prompt 与前缀共享关系。
代价：可能产生永远不会被再用的 B 尾部 KV。
02

真实输出反馈重放

vLLM / SGLang Multi-turn Benchmark

把原始回答 A 替换成 Qwen 实际生成的 B，工具结果仍用 T。

第 1 轮
P→ Qwen 生成 →B
第 2 轮输入
PBT
B 的 Decode KV 有机会复用
保留：会话轮次、工具消息结构。
代价：实际 Prompt 已不同于原始 Trace。
03

真实 Agent 闭环

OpenHands / ThunderAgent 类真实执行

Qwen 回答后，真的调用工具；工具结果也可能变成 T′。

第 1 轮
P→B→ 执行工具 →T′
第 2 轮输入
PBT′
KV 有机会自然复用
优点：最接近真实 Agent 运行。
代价：工具结果、轮数、请求长度都可能改变。
04

合成消息 + 输出反馈

NVIDIA TensorRT-LLM Trace Replay

只按原始消息长度合成 P′、T′；Qwen 仍真实生成 B。

第 1 轮
P′（合成）→ Qwen →B
第 2 轮输入
P′BT′（合成）
B 的 Decode KV 有机会复用
保留：消息长度、角色、时序和工具等待。
代价：正文已合成；Thinking 可能造成新分叉。
05

根据 Block Hash 重建

AgentX / AIPerf

没有 Prompt 正文；用同一个 Hash 生成同一段合成 Token。

第 1 轮
X1 X2 X3 X4→ Qwen →B
第 2 轮输入（仍按原 Hash）
X1 X2 X3 X4X5 X6
B 不保证出现在下一轮
保留：原始 Hash 的前缀共享与分叉。
代价：上一轮生成的 B 可能无法复用。
06

强制输出原始 Token

Teacher Forcing · 可选研究控制方法

不让 Qwen 自由生成 B，而是强制让它处理 A 的 Token 序列。

第 1 轮
P→ 强制处理 →A
第 2 轮输入
PAT
原始一致，但实现较复杂
优点：原始内容与计算状态都能精确对齐。
代价：必须提取精确 Token，且可能改推理路径。

一眼看懂：它们到底保留了什么？

方案第 2 轮输入原始内容 / Hash上一轮 Decode KV成本
① 固定原始 PromptP+A+T保留B 不可复用低
② 模型输出反馈P+B+T改变回答B 可复用*低～中
③ 真实 Agent 闭环P+B+T′运行轨迹可能改变B 可复用*高
④ 合成消息反馈P′+B+T′保留结构，不保留正文B 可复用*中
⑤ AgentX Hash 重建X1…X6保留 Hash 共享B 不保证可复用中
⑥ 强制原始输出P+A+T保留A 可复用*高

* 还需满足 Token IDs、Chat Template、位置、Block 边界和 Recurrent State 一致，并且缓存仍驻留。若内部 Reasoning 未进入下一轮历史，即使反馈答案，也可能无法复用完整 Decode KV。

放到你的 Qwen3.5 / vLLM 0.30.0 实验里

LMCache：优先比较 ① 和 ②

① 严格复现原始 Prompt 的 LCP；② 让 Qwen 输出 B 参与下一轮，从而验证真实 Decode KV 的复用与驱逐。两者不能混报一个 Hit Rate。

AgentX：优先用 ⑤

它的核心价值就是 Hash 共享结构；不要为了复用 B 而随意修改 X5、X6，否则不再是原始 AgentX 的前缀访问模式。

最重要的原则：固定原始 Trace 时，保留了原始前缀结构，但生成的尾部 KV 可能不会被再次需要；反馈模型输出时，保留了实际计算状态的一致性，但改变了原始 Trace。实验前先决定要保留哪个不变量。
